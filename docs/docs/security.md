# Security

If you believe you’ve found a security issue in libjzx:

- Prefer using GitHub’s **Security Advisories** (private disclosure) if enabled for this repository.
- Otherwise, open a GitHub issue with only non-sensitive details and ask for a private channel to share a reproducer.
